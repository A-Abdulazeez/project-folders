SafeBank Transaction Simulator

Project Reflection

Abdullahi Abdulazeez

The Safe Bank Transaction Simulator demonstrates basic banking operations, including deposits, withdrawals, and balance checking. Working on this project highlights the importance of transaction accuracy, security, and proper validation when handling financial operations.

Testing and Checklist

-  Deposit transactions work correctly.
-  Withdrawals work when sufficient funds are available.
-  Withdrawals are rejected when funds are insufficient.
-  Account balances update correctly.
-  Invalid transaction amounts are rejected.
-  Transaction records display correctly.

Known Limitations

- The simulator does not connect to a real banking system.
- Transactions are not processed through real payment networks.
- Advanced security features, such as multi-factor authentication, are not included.
- The application is just assignment.
